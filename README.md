# Генератор списка покупок (GigaChat + Streamlit)

## Запуск
1. Установите зависимости: `pip install -r requirements.txt`
2. Создайте файл `.env` и добавьте ключ: `GIGACHAT_CREDENTIALS=ваш_ключ`
3. Запустите: `streamlit run streamlit_app.py`

## Тесты
1. Нормальный ввод: «Омлет», 2 чел., «Список продуктов» -> появляется список.
2. Пустой ввод: поле пустое -> «Напишите, что хотите приготовить.»
3. Длинный ввод: > 500 символов -> «Слишком длинный текст...»
